API Documentation

Integrate weather predictions into your applications

Base URL

http://localhost:5000

All endpoints return JSON responses. No authentication is required.

GET

/api/predict

Get weather predictions for a specific location and month. Returns temperature, humidity, wind speed, rain probability, and additional derived metrics.

Parameters

NameTypeRequiredDescription
latfloat✅ Latitude (-90 to 90)
lonfloat✅ Longitude (-180 to 180)
monthint❌ Month (1-12). Defaults to current month

Example Request

GET /api/predict?lat=28.6139&lon=77.2090&month=6

Example Response

{
  "location": { "latitude": 28.6139, "longitude": 77.209 },
  "month": 6,
  "month_name": "June",
  "predictions": {
    "temperature": { "value": 38.2, "unit": "°C", "feels_like": 37.1 },
    "humidity": { "value": 45.3, "unit": "%" },
    "wind_speed": { "value": 22.1, "unit": "km/h" },
    "rain": { "prediction": "No Rain", "probability": 28.5, "unit": "%" }
  },
  "condition": { "text": "Hot & Sunny", "icon": "🔥" },
  "additional": {
    "dew_point": 27.3,
    "uv_index": 8,
    "visibility": 16.2,
    "pressure": 1011.5
  }
}

GET

/api/forecast

Get a 12-month weather forecast for a location. Returns temperature, humidity, wind speed, and rain probability for every month.

Parameters

NameTypeRequiredDescription
latfloat✅Latitude (-90 to 90)
lonfloat✅Longitude (-180 to 180)

Example Request

GET /api/forecast?lat=40.7128&lon=-74.0060
